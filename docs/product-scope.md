# 제품 범위

## 사용자 유형과 권한

| 유형          | 역할                     | 주 사용 기기    | 할 수 있는 일                                                                           |
| ------------- | ------------------------ | --------------- | --------------------------------------------------------------------------------------- |
| 방문자        | (비로그인)               | 모바일          | 프로그램·공지·동아리·공간·센터 안내·FAQ·정책 문서 열람                                  |
| 회원          | `member`                 | 모바일          | 프로그램 신청/취소, 공간 예약/취소, 동아리 가입 신청, 1:1 문의, 내 정보·동의 내역, 탈퇴 |
| 동아리원      | `member` + 동아리 멤버십 | 모바일          | 소속 동아리 소식·일정, 마스킹된 동아리원 명단                                           |
| 동아리 담당자 | `member` + 담당 동아리   | 모바일·데스크톱 | 담당 동아리의 회원(연락처·역할·제외)·가입 신청·출석·소식·소개 관리 (센터 직원이 지정)   |
| 센터 직원     | `staff`                  | 모바일·데스크톱 | 공지·프로그램·신청·공간 예약·동아리·문의/FAQ 관리, 회원 조회, 출석부(동아리·프로그램)   |
| 최고 관리자   | `admin`                  | 모바일·데스크톱 | 직원 권한 + 회원 역할/상태 변경, 정책 문서, 감사 로그                                   |
| 개발자        | `developer`              | 모바일·데스크톱 | 최상위 역할 — 모든 권한 + 개발자 도구, 개발자 역할 부여·개발자 계정 변경                |

권한 매핑: `src/domain/permissions.ts`. 프론트엔드 권한 검사는 표시용이며 서버가 다시 검증한다.

## 사이트맵

사용자 웹

- `/` 홈 (오늘 운영시간, 마감 임박 프로그램, 공지, 센터 이용 목차)
- `/programs`, `/programs/[id]`, `/programs/[id]/apply`
- `/spaces`, `/spaces/[id]` (시간대 선택 예약)
- `/clubs`, `/clubs/[id]` (가입 신청 / 동아리원 전용 탭)
- `/notices`, `/notices/[id]`
- `/qna` (FAQ + 내 문의), `/qna/new`, `/qna/[id]`
- `/about` (센터 소개·운영시간·오시는 길·층별 안내·문의)
- `/policies/terms|privacy|no-email`
- `/login`, `/signup`, `/signup/verify`, `/password/forgot`, `/password/reset`
- `/my` (프로그램 신청·공간 예약·동아리), `/my/applications/[id]`, `/my/profile`, `/my/withdraw`

관리자 웹 (`/admin/login` 별도 진입)

- 대시보드, 공지, 프로그램, 프로그램 신청, 공간 예약·공간 설정, 동아리·가입 신청, 문의·FAQ, 회원, 정책 문서, 감사 로그

## 핵심 흐름

1. 프로그램 신청: 목록 → 상세 → (로그인) → 신청 폼(연락처·동의) → 접수 완료(서버 발급 접수번호) → 마이페이지 상태 확인 → 취소 기한 내 취소
2. 공간 예약: 공간 목록 → 날짜 선택 → 빈 시간대 범위 선택 → 인원·목적·동의 → 승인 대기 → 관리자 확정/반려
3. 동아리 가입: 동아리 상세 → 가입 동기·동의 → 검토 대기 → 승인 시 동아리원 영역 열림
4. 문의: FAQ 확인 → 1:1 문의 작성 → 관리자 답변 → 본인만 열람
5. 관리자 처리: 대시보드 대기 건수 → 목록 필터 → 일괄 승인/반려(사유) → 결과(성공/실패 건) → 감사 로그

## 우선순위

MVP (이번 구현)

- 위 사용자·관리자 화면 전체, mock adapter, 계약 초안, 반응형(모바일 우선), 접근성 기본, 단위/컴포넌트/E2E 테스트

이후

- 실서버 연동(http adapter 활성화), OAuth 4사 실제 연동·계정 연결/해제
- 첨부파일 업로드(공지·프로그램 이미지), 알림(메일/문자/푸시)
- 만 14세 미만 법정대리인 동의 온라인 절차
- 대기 신청(대기열) — 실제 정책 확인 후에만
- 개인정보 포함 내보내기(CSV) — 요구사항·권한 확정 후에만
- 갤러리·식단 등 공식 사이트의 기타 게시판

## 법률 검토 필요

개인정보 수집 항목·보유 기간, 만 14세 미만 아동 동의, 개인정보처리방침 확정본, 마케팅 수신 동의 문구, 감사 로그 보관 기간, CCTV/사진 게시 동의 등은 운영 정책과 법률 검토가 필요하다. 이 문서는 법적 적합성을 보장하지 않는다.
