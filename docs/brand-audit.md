## 이미지

- 사용자 홈에는 갤러리에서 확인한 [센터 건물 전경](https://www.j-youth.org/kor/images/sub/info_00_01.jpg)을 공식 시설안내 원격 주소로 표시한다. 사진을 불러오지 못해도 방문 정보와 링크는 남는다.
- 메인 배너 이미지는 사용 권한이 불분명해 사용하지 않았다.
- 동아리 소개·갤러리(mock 데이터)는 `docs/research/clubs.json`(수집일 2026-10-17)의 공식 채널 이미지·영상을 **원격 주소 그대로** 참조한다 (`src/api/mock/research.ts`). 화면에 출처 링크와 수집일을 표시한다.
- **사용 권한 미확인**: 사진·영상의 저작권은 센터와 원저작자에게 있다. 운영 공개 전에 센터의 서면 사용 허락을 받는다.
- **청소년 초상**: 얼굴이 식별되는 이미지(`showsMinorsFaces: true`, 20건)는 제외했다. 영상은 썸네일 얼굴 검수를 하지 않았으므로 갤러리에서 썸네일 없이 제목 목록으로만 보여 준다. 관리자 폼에도 동의 확인 안내를 넣었다.
- **네이버 블로그 이미지**: 원본 호스트(postfiles.pstatic.net)는 외부 Referer 를 차단해 `mblogthumb-phinf.pstatic.net` 썸네일 주소를 쓴다. 외부 서비스의 핫링크라 언제든 막힐 수 있으므로, 센터 허락 후 S3 등 자체 저장소로 옮겨(re-host) 등록한다.
- 이미지 요청은 `referrerPolicy="no-referrer"` 로 보낸다.
